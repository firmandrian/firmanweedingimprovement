# Undangan Pernikahan Firman & Fadia

## Menjalankan website
1. Buka folder ini di VS Code.
2. Simpan file musik MP3 yang boleh digunakan di `assets/`.
3. Nama file musik yang dipanggil oleh website adalah `the-way-you-look-at-me.mp3`.
4. Buka `script.js`, lalu ganti `GANTI_DENGAN_NOMOR_WA` dengan nomor WhatsApp tujuan RSVP, format internasional tanpa `+`, spasi, atau strip. Contoh: `6281234567890`.
5. Jalankan `index.html` menggunakan Live Server.

## File proyek
- `index.html`: struktur dan konten undangan.
- `style.css`: tampilan responsif, warna, layout, dan animasi.
- `script.js`: musik, countdown, RSVP, scroll reveal, dan efek kelopak.
- `assets/garden-watercolor.png`: ilustrasi latar watercolor yang dibuat untuk desain ini.

## Catatan musik
File MP3 tidak disertakan. Letakkan file audio yang kamu miliki atau berlisensi untuk digunakan di folder `assets/`, lalu pastikan namanya `the-way-you-look-at-me.mp3`. Jika nama file berbeda, sesuaikan path di `script.js`.
